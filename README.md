# Text To Speech Converter

A sleek, responsive web application that converts written text into spoken audio in real-time. Built using pure HTML5, CSS3, and vanilla JavaScript, this project leverages the native Web Speech API to provide cross-browser voice synthesis without requiring external cloud APIs or servers.

# live link - https://gregarious-tiramisu-8b8260.netlify.app/

 Features

Real-Time Voice Synthesis: Instantly converts any typed text into clear, audible speech using the browser's native engine.
Dynamic Voice Selection: Automatically detects and populates a dropdown menu with all available system voices installed on the user's device (e.g., Google, Microsoft, Apple, or default operating system voices).
Language & Accent Support: Seamlessly switches between different languages, accents, and gender profiles based on the selected voice.
Modern UI Design: Features a rich gradient aesthetic (`#490d61` to `#010758`) with custom layouts for input and action controls.
Responsive Architecture: Built with a centered layout structure using CSS Flexbox for uniform viewing on multiple screen resolutions.
